Complete App Flow

Customer app and admin panel, pickup-only model. No delivery, no ERP sync, no payment gateway in V1.

CUSTOMER APP

User Journey

From first open to picking up the order at the store.
1

Onboarding

  • User opens the app → Firebase phone auth (OTP) → JWT issued
  • GPS auto-detects location → nearest store assigned
2

Browse

  • Products fetched from the store's product list (weekly CSV import by store staff)
  • Stock shown with a disclaimer — "Availability may vary, confirmed by store before pickup"
  • User searches / browses → adds items to cart
3

Cart

  • Add / update / remove items → stock capped, price snapshot taken
  • User optionally changes delivery address
  • Mismatch with store's delivery radius → alert shown, cart cleared, new store assigned
4

Checkout

  • Cart validated — stock, price & store-open checks re-run
  • All checks pass → order placed (idempotency key attached)
  • Order created → status PENDING, cart marked ORDERED
5

Store Confirms — Admin Panel

  • Staff sees the PENDING order in real time
  • Reviews items → checklist: available / unavailable per item
  • Confirms → total adjusted automatically if some items are unavailable
  • Status → CONFIRMED, user notified
6

Store Prepares

  • Staff packs the available items
  • Marks the order "Ready for Pickup"
  • Status → READY_FOR_PICKUP, user notified
7

Pickup

  • User visits the store, collects the order
  • Staff marks the order complete
  • Status → PICKED_UP, user notified
Inventory is not ERP-synced in V1 — each store shares its product list via a weekly file import. Stock shown in the app may not always reflect what's on the shelf right now.
