Order Lifecycle — Pickup to Delivery

End-to-end flow from ERP product sync through order placement, store confirmation, and store-staff delivery. V1 — no payment gateway, no third-party courier.

ERP SYNC

Working of Products & Stock through ERP Sync

01
POST /emedix-webhook/product

Products are added by ERP software on every product add — upsert products into MySQL DB.

02
POST /emedix-webhook/product-stock

Product stock is updated by ERP software on every update on stock.

ORDER LIFECYCLE

Complete Flow — Order to Delivery

Eight steps, three actors — the user, Swil ERP, and store staff. Status moves strictly forward: no skipping, no downgrading.
1
User

User authenticates, current location is automatically detected, nearest store to user location is assigned, products fetched from that specific store, browse products, add items to cart, change delivery address (optional), cart validation happens & proceeds to checkout.

2
User POST /orders → PENDING

Order is created & marked as PENDING in DB.

3
ERP POST /emedix-webhook/orders/pending

ERP software fetches pending orders based on store_id every 15 minutes. Orders are automatically created in their system.

4
Store Staff

Store staff checks item availability, collects product items, makes invoice for the specific order manually in the ERP Software.

5
ERP POST /emedix-webhook/invoice → CONFIRMED

ERP software sends invoice with all necessary charges. Order is marked as CONFIRMED in DB — user receives a notification.

6
Store Staff POST /delivery/assign → DISPATCHED

Endpoint hit by store staff (not third-party delivery) to assign a delivery partner to the specific order — with delivery partner's details like name, phone number, estimated delivery time — via Swagger UI. Status updated to DISPATCHED / Out for Delivery. User receives a notification that the order is out for delivery and will reach soon in the given time period. Order is trackable — communication between user & delivery partner.

7
Store Staff GET /api/delivery/:order_no/details

Endpoint to get all information of the order — like user, delivery address, product items details.

8
Store Staff POST /delivery/complete/:order_no → DELIVERED

Endpoint hit by delivery partner in Swagger UI when the order is delivered to the user's delivery location. Order marked as DELIVERED. Payment is Cash on Delivery — invoice (bill) is sent to the user by the delivery partner. User receives a notification that the order is delivered. Customer support is provided.

✓
Order complete — DELIVERED
